# rokid-conversate 조사 요약

작성: 2026-11-05. 판정 표기는 네비 레포와 같다: **확인**(직접 실행) / 문서확인(출처에 적힌 것) / 미확인.
직접 실행한 것: 서버 단위 테스트, 한국어 TTS 음성으로 Whisper 받아쓰기, 안경 앱 빌드·단위 테스트·Paparazzi 화면. **안경 실기에서는 아무것도 돌려보지 않았다.**

## 목표
Even Realities G2 의 대화 지원 기능 **Conversate** 를 Rokid 안경에서 비슷하게 만든다. 1단계는 실시간 자막.

## 구조
```
[안경 APK (Kotlin)]  마이크 16kHz PCM ─ WebSocket ─▶ [서버 (Python)] ─ faster-whisper
        ▲                                                │
        └──────────── 자막 JSON ◀─────────────────────────┘
   폰(iPhone)은 개인용 핫스팟으로 인터넷만 준다. 폰 앱 없음.
```
- 사용자 폰이 iPhone 이라 폰 쪽 CXR-M(안드로이드 전용)을 쓰는 구조는 불가. 네비 레포와 같은 "안경 단독 앱 → 서버 WebSocket" 구조.
- 서버를 Python 으로 한 것은 사용자 결정 (네비 서버는 TypeScript). Whisper·LLM 쪽 라이브러리가 Python 에 많다.

## G2 Conversate 정리 (문서확인)
| 기능 | 내용 |
|---|---|
| 동작 | 안경 마이크 4개 → BLE → 폰 앱 → 클라우드. 안경-폰 연결과 폰 인터넷이 필수 |
| 실시간 자막 | 시선을 살짝 올리면 보이는 위치 |
| AI 힌트 (Cues) | 제안(되묻기·반박·방향), 답변(올린 자료에서), 개념(용어 설명), 인물(사람·회사 배경). 몇 초 뒤 사라짐 |
| 사전 노트 (Prep Notes) | 대화 전에 메모·문서를 올려 힌트 정확도를 높임 (2026-03 추가) |
| 번역 | 업데이트로 추가 |
| 요약·할 일 | 끝나면 앱에 저장, 할 일은 QuickList 로 |
| 개인정보 | 녹음 저장 없음, 글자 기록과 요약만. 각 기능 끌 수 있음 |
| 언어 | 지원 문서 기준 한국어 포함 약 20개 (마케팅 페이지는 33~35개 이상) |
| 리뷰 | 자막은 쓸 만함, 요약은 결론을 잘 못 냄(Engadget), 힌트가 한 박자 늦고 쓸모없는 인물 소개가 잦음(Lifehacker), 환경 영향 큼(Geeky Gadgets) |

## Rokid 쪽 근거
| 주제 | 판정 | 내용 |
|---|---|---|
| 안경 OS | 문서확인 | YodaOS-Sprite, Android 12 (API 32). 일반 APK 를 `adb install` (5핀 개발 케이블 + Hi Rokid 개발자 모드) |
| 안경에서 직접 인터넷 | 문서확인 | Wi-Fi 6 내장. 네비 앱·Rokid-Maps·Rokid_Claude 가 안경에서 직접 WebSocket/HTTP |
| Wi-Fi 배터리 | 문서확인 | Wi-Fi 는 평소 꺼져 있고 켜면 배터리가 빨리 닳는다는 후기 (note.com). 오디오를 계속 보내므로 **가장 큰 위험** |
| iPhone 핫스팟 | 문서확인 | 연결 기기가 없으면 잠들어 안경이 못 붙음. 설정 화면을 켜 둬야 함 (네비 레포) |
| 마이크 | 미확인 | 4마이크(리테일 스펙) / 8채널(커뮤니티 역공학). 호출어 감지용 보조 칩(NXP RT600)이 따로 있음. **서드파티 앱이 `AudioRecord` 로 계속 녹음할 수 있는지, 기본 비서와 충돌하는지 모름** |
| 구글 서비스 | 문서확인 | 없음. 그래서 받아쓰기는 서버에서 |
| 화면 | 문서확인 | 480x640 녹색 단색. 네비 앱과 같은 480x282 논리 단위, 아래 가운데 |
| 입력 | 문서확인 | 탭=ENTER, 쓸기=DPAD 좌우/183/184, 더블탭=202 또는 BACK. 길게 누르기·다리 버튼은 시스템 |
| R08 링 | 문서확인 | R08 Access Bridge 가 접근성으로 포커스 노드에 스크롤 앞/뒤·클릭, 더블탭=전역 뒤로. 브리지 없이 Stable 모드면 미디어 키 |

## Whisper 실측 (확인)
gTTS 로 만든 한국어 문장 10.2초를 실시간 속도로 보냄. 클라우드 세션 CPU 4코어, `small` 모델, int8.
```
 4.10s partial #1: 안녕하세요 오늘
 6.83s partial #1: 안녕하세요 오늘 회의에서는 다
10.52s partial #1: 안녕하세요 오늘 회의에서는 다음 분기마케팅 예산을 논의하겠습니다.
15.95s FINAL   #1: 안녕하세요 오늘 회의에서는 다음 분기 마케팅 예산을 논의하겠습니다. 첫 번째 안건은 광고 채널 정리 입니다.
```
- 받아쓰기는 정확. 말이 끝나고 확정까지 약 5초, 부분 자막은 1~4초 뒤처짐.
- TTS 음성(깨끗, 화자 1명)이라 실제 대화보다 쉽다. 실제 대화·소음·여러 화자는 미확인.
- 빠르게 하려면: GPU (`WHISPER_DEVICE=cuda`), `turbo` 모델, 또는 부분 자막 간격 늘리기.
